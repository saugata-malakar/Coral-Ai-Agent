QUICK DEPLOYMENT GUIDE

3 SIMPLE STEPS (takes 10-15 minutes):

1. INSTALL GOOGLE CLOUD SDK
   Download: https://cloud.google.com/sdk/docs/install

2. GET YOUR PROJECT ID
   Go to: https://console.cloud.google.com
   Copy your PROJECT_ID

3. RUN THESE COMMANDS:

   # Login
   gcloud auth login

   # Set project
   gcloud config set project YOUR_PROJECT_ID

   # Build
   gcloud builds submit --tag gcr.io/YOUR_PROJECT_ID/coastal-ai-agent

   # Deploy
   gcloud run deploy coastal-ai-agent \
     --image gcr.io/YOUR_PROJECT_ID/coastal-ai-agent \
     --platform managed \
     --region us-central1 \
     --allow-unauthenticated \
     --set-env-vars JWT_SECRET=YOUR_JWT_SECRET,TAVILY_API_KEY=YOUR_TAVILY_KEY,GOOGLE_CLIENT_ID=YOUR_CLIENT_ID,GOOGLE_CLIENT_SECRET=YOUR_SECRET,GEMINI_MODEL=gemini-2.5-flash

   # Get URL
   gcloud run services describe coastal-ai-agent --region us-central1 --format 'value(status.url)'
