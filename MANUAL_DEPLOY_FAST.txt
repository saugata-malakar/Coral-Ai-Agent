STEP 2: Replace Dockerfile (1 min)
──────────────────────────────────

1. Click "Files" tab (top left)

2. You should see a "Dockerfile" listed

3. Click on it to open

4. Delete ALL content (Ctrl+A, Delete)

5. Copy this and paste:

   │ FROM python:3.11-slim                                           │
   │ WORKDIR /app                                                    │
   │ RUN apt-get update && apt-get install -y --no-install-recomm... │
   │     build-essential curl && rm -rf /var/lib/apt/lists/*         │
   │ COPY requirements.txt .                                         │
   │ RUN pip install --no-cache-dir -r requirements.txt              │
   │ COPY . .                                                        │
   │ ENV PYTHONUNBUFFERED=1 PYTHONDONTWRITEBYTECODE=1 PORT=7860     │
   │ EXPOSE 7860                                                     │
   │ CMD ["python", "-m", "uvicorn", "main:app", "--host", ...     │
   └─────────────────────────────────────────────────────────────────┘

   👉 Copy from: HF_SPACES_DOCKERFILE.txt (in your folder)

7. Wait 10 seconds
