# ⚡ QUICK REFERENCE: DEPLOY IN 15 MINUTES

## 🚀 5-STEP DEPLOYMENT

### Step 1: Create HuggingFace Space (2 mins)
```
1. Go to https://huggingface.co/spaces
2. Click "Create new Space"
3. Name: coastal-ai-agent
4. Type: Docker
5. Visibility: Public
6. Create Space
```

### Step 2: Clone & Prepare (3 mins)
```bash
# Clone the space
git clone https://huggingface.co/spaces/YOU/coastal-ai-agent
cd coastal-ai-agent

# Copy all project files
cp -r /path/to/Coral-Ai-Agent-main/* .

# Create assets dir
mkdir -p api/static/assets

# Add professor photo (REQUIRED!)
cp /path/to/prof-photo.jpg api/static/assets/
```

### Step 3: Push to HF (2 mins)
```bash
git add .
git commit -m "Deploy Coastal AI v2.0 - OAuth, OTP, Thinking Modes, Prof Profile"
git push
```

### Step 4: Add Secrets (5 mins)
Go to **Space Settings** → **Secrets** → Add these 7 variables:

```
GOOGLE_CLIENT_ID = <your-value>
GOOGLE_CLIENT_SECRET = <your-value>
SENDGRID_API_KEY = <get-from-sendgrid-free>
JWT_SECRET = <copy-from-.env>
TAVILY_API_KEY = <copy-from-.env>
GCP_PROJECT = <copy-from-.env>
GCP_SA_KEY_PATH = <copy-from-.env>
```

### Step 5: Wait & Test (3 mins)
- HF Spaces auto-builds (~10 minutes)
- Check build logs
- Once "App is running" → click link
- Test: Signup → Verify Email → Chat

## 📝 SENDGRID SETUP (5 mins, Free)

1. Go to https://sendgrid.com/
2. Sign up (free tier: 100 emails/day)
3. Verify sender email (can use any email)
4. Settings → API Keys → Create API Key
5. Copy API Key → Add to HF Secrets as `SENDGRID_API_KEY`
